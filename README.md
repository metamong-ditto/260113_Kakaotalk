# 카카오톡 오픈채팅방 인원 수 확인 도구

특정 키워드로 카카오톡 오픈채팅방을 검색하고, 채팅방 이름과 인원 수를 확인하는 프로그램입니다.

## 기능

- 키워드로 오픈채팅방 검색
- 채팅방별 인원 수 확인
- 인원 수 기준 정렬
- 통계 정보 제공 (총 인원, 평균, 최대/최소)
- CSV 파일로 결과 저장
- 대화형 모드 지원

## 설치

### 요구 사항

- Python 3.10 이상
- Chrome 브라우저

### 의존성 설치

```bash
pip install -r requirements.txt
```

## 사용법

### 대화형 모드

```bash
python main.py
```

### 직접 검색

```bash
# 기본 검색
python main.py "파이썬"

# 최대 50개 결과
python main.py "주식" -n 50

# CSV로 저장
python main.py "영어" -o result.csv

# 브라우저 창 표시 (디버깅용)
python main.py "게임" --no-headless
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `keyword` | 검색할 키워드 (없으면 대화형 모드) |
| `-n`, `--max-results` | 최대 결과 수 (기본값: 20) |
| `-o`, `--output` | 결과를 저장할 CSV 파일명 |
| `--no-headless` | 브라우저 창을 표시 |

## 모듈로 사용

```python
from kakao_openchat_scraper import search_openchat, print_results

# 검색 실행
rooms = search_openchat("파이썬", max_results=10)

# 결과 출력
print_results(rooms, "파이썬")

# 개별 채팅방 정보 접근
for room in rooms:
    print(f"{room.name}: {room.member_count}명")
```
